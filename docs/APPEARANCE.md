# هوية الواجهة — slate/amber الداكنة مع خط Tajawal

## آخر اعتماد من المستخدم

اعتمد المستخدم (٢٣/٠٩/٢٠٢٦) لوحة ألوان برنامجه الثاني: **slate داكن عميق مع
accent كهرماني (amber)** للمنظومة كلها، مع خط **Tajawal** المحلي. أُلغيت الهوية
البنفسجية/البرتقالية السابقة كليًا دون الرجوع إلى أي هوية أقدم.

- الخلفية الرئيسية: slate-950 `#020617`؛ البطاقات والقائمة الجانبية: slate-900 `#0F172A`؛ الحدود: slate-800 `#1E293B` والحقول slate-700 `#334155`.
- لون التمييز الأساسي: amber-500 `#F59E0B` (hover ‎`#FBBF24`)، والنص فوقه slate-950 `#020617` للوضوح.
- عناوين الجداول ولمسات التحديد: amber-300 `#FCD34D` فوق سطح كهرماني داكن `#201708`.
- أسماء رموز theme.css ثابتة للتوافق مع ملفات التنسيق القائمة (`--brand-gold` تحمل الـamber المعتمد).
- كتلة التعريف بالشريط الجانبي خمسة أسطر بترتيب ثابت: وزارة الداخلية ← قطاع الأمن المركزى ← منطقة وسط وجنوب سيناء ← قطاع وسط سيناء ← قسم التعيينات.
- ألوان النجاح والخطأ وحالات اليومية مستقلة عن لون التنقل، ومعها وصف نصي.
- الأرقام تظل عربية مشرقية؛ الكميات لا يتغير تنسيقها `٠٫١٢٠` و`٧٥٫٠٠٠`.

الهوية تخص واجهة التطبيق. **المعاينات الورقية والمستندات الرسمية ولوجو الوحدة لا
تأخذ ألوان الواجهة**؛ يحتفظ الورق بخلفيته البيضاء وألوانه الخاصة.

## الخط والتنظيم

ملفات Changa كاملة ومحلية، بالأوزان ٤٠٠/٥٠٠/٦٠٠/٧٠٠ والترخيص الأصلي (OFL)،
مُشتقّة من الخط المتغير الرسمي لمستودع google/fonts بدون أي حذف من الحروف.
تفاصيل المصدر في `static/fonts/README.md`.

المصدر الوحيد لألوان الواجهة هو `static/css/theme.css`. تستخدم شاشة البداية الأصلية
نفس الخط والثيم عبر `desktop/appearance.py`، بدون تحميل أصول خارجية عند التشغيل.
لا يغير التصميم قواعد البيانات أو عزل الشهور أو النسخ أو الترحيل.

## التحقق

- **١١٣ اختبار Python ناجحًا** للخطوط المحلية والتباين والبيانات والمستندات ومسارات HTTP وقسم التاميدات.
- ملفات الخطوط ومنطق الأرقام وطبقة البيانات ومولدات المستندات لم تتغير؛ تم التحقق ببصمات الملفات وبعدادات البيانات الحقيقية.
- اختبار متصفح فعلي يتحقق من الخط الذي يرسم الحروف والأرقام عبر Chromium،
  وليس فقط قيمة `font-family` في CSS.
- اختبار حفظ النماذج، إظهار/إخفاء الشهادة، التبويبات السبعة، الكميات العربية، القوائم،
  الألوان المحسوبة، والهواتف دون تمرير أفقي أو طلبات أصول خارجية.
- تباين نص الزر الداكن مع الذهبي، والنص الفاتح مع الكحلي، لا يقل عن ٧:١.
- اختبارات Windows الأصلية مُعدّة لفحص الخط والثيم الكحلي/الذهبي أيضًا؛ لم يُنفّذ
  بناء Windows جديد لهذه الاستعادة. تأكيد المثبّت وتسليمه مؤجل حسب اختيار المستخدم.

### إعادة اختبار المتصفح

الأدوات التالية للتطوير فقط، وليست اعتماديات البرنامج المثبت:

```bash
npm install --prefix .arena/browser --no-save playwright@1.57.0 @sparticuz/chromium@143.0.4
.venv/bin/python tests/browser/serve.py
# من طرفية أخرى:
node tests/browser/appearance.cjs
```

في بيئات Linux المصغرة قد يلزم توفير مكتبات NSS الخاصة بـ Chromium أو استخدام
`LD_LIBRARY_PATH` لمكتبات الحزمة المرفقة. الخادم الاختباري ينشئ مجلد بيانات مؤقتًا،
وسكربت المتصفح يرفض إضافة أي سجلات إلى خادم لا يحمل علامة الاختبار المعزول.
المخرجات داخل `.arena/appearance-results/` ولا تُرفع إلى GitHub.

لم تُختبر الطباعة الفيزيائية أو نوافذ حفظ الملفات الأصلية على جهاز المستخدم بهذا الاختبار.
