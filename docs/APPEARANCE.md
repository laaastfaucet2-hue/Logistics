# هوية الواجهة — إصدار ٢٫١٫٠

## الاعتماد

طلب المستخدم تغيير خط البرنامج وألوانه إلى الأحمر والأصفر، واعتمد استخدام
IBM Plex Sans Arabic مع **الكتابة السوداء على الأصفر** والجداول الفاتحة.
الهوية تخص واجهة التطبيق؛ اسم المنظومة وشعار المخازن مستقلان عن علامة المطعم.
لا يُغيَّر لوجو المستخدم ولا تُنسخ ألوان الواجهة إلى مستندات Excel/Word الرسمية.

## مصادر الاختيار

- عائلة IBM Plex مفتوحة المصدر ومصممة للاستخدام في واجهات المستخدم، وتضم نسخة عربية. [1](https://github.com/IBM/plex)
- درجات الأحمر `#DA291C` والأصفر `#FFC72C` من مراجع ألوان علامة McDonald's. [2](https://brandscolorcodes.com/mcdonalds-color-codes/)
- ملفات الخط كاملة ومحلية، مع الأوزان ٤٠٠/٥٠٠/٦٠٠/٧٠٠ والترخيص الأصلي.
  تفاصيل المصدر في `static/fonts/README.md`.

## التوزيع

- القائمة الجانبية وشريط النافذة: أحمر، وكتابة بيضاء واضحة.
- التحديد والأزرار الأساسية ورؤوس الجداول: أصفر، وكتابة سوداء.
- حقول الإدخال والجداول والبطاقات: خلفيات فاتحة، مع نصوص داكنة وحدود ظاهرة.
- ألوان النجاح والخطأ وحالات اليومية مستقلة عن لون التنقل، ومعها وصف نصي.
- أحجام النصوص والأرقام أكبر من الإصدار السابق، دون خلط Cairo وChanga.
- الأرقام تظل عربية مشرقية؛ الكميات لا يتغير تنسيقها `٠٫١٢٠` و`٧٥٫٠٠٠`.
- شاشة البداية الأصلية تستخدم نفس ملفات CSS والخط عبر `desktop/appearance.py`.
- لا يغير التصميم قواعد البيانات أو عزل الشهور أو نسخها أو ترحيلها.

المصدر الوحيد لألوان الواجهة هو `static/css/theme.css`. لا تضف ألوان كحلية قديمة
إلى شاشة جديدة، ولا تحمل خطوطًا من الإنترنت أثناء التشغيل.

## التحقق

- **٤٨ اختبار Python ناجحًا** على نسخة التطوير، ببيانات مؤقتة معزولة.
- اختبار متصفح فعلي يتحقق من اسم الخط الذي يرسم الحروف والأرقام عبر Chromium،
  وليس فقط قيمة `font-family` في CSS.
- اختبار حفظ النماذج، إظهار/إخفاء الشهادة، التبويبات السبعة، الكميات العربية، القوائم،
  الألوان المحسوبة، وشاشات الهاتف دون تمرير أفقي أو طلبات أصول خارجية.
- تباين أسود/أصفر يتجاوز ٧:١، وأبيض/أحمر يتجاوز ٤٫٥:١.
- اختبار Windows الأصلي يتحقق كذلك من تحميل الأوزان الأربعة وشريط أحمر وزر أصفر
  بكتابة سوداء في شاشة البداية ثم لوحة العمل. نجاحه يُوثَّق بعد انتهاء بناء هذا الإصدار.

### إعادة اختبار المتصفح

الأدوات التالية للتطوير فقط، وليست اعتماديات البرنامج المثبت:

```bash
npm install --prefix .arena/browser --no-save playwright@1.57.0 @sparticuz/chromium@143.0.4
.venv/bin/python tests/browser/serve.py
# من طرفية أخرى:
node tests/browser/appearance.cjs
```

في بيئات Linux المصغرة قد يلزم توفير مكتبات NSS الخاصة بـ Chromium أو استخدام
`LD_LIBRARY_PATH` لمكتبات الحزمة المرفقة. الخادم الاختباري ينشئ مجلد بيانات مؤقتًا،
وسكربت المتصفح يرفض إضافة أي سجلات إلى خادم لا يحمل علامة الاختبار المعزول.
المخرجات داخل `.arena/appearance-results/` ولا تُرفع إلى GitHub.

لم تُختبر الطباعة الفيزيائية أو نوافذ حفظ الملفات الأصلية على جهاز المستخدم بهذا الاختبار.
