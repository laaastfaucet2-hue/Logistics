# قاعدة التواريخ العربية — يوم/شهر/سنة

## الصيغة الملزمة

**`dd/mm/yyyy`**، بصفر بادئ وأرقام عربية مشرقية: **٢٢/٠٩/٢٠٢٦**.
لا يعتمد العرض أو الإدخال على لغة Windows أو إعدادات المتصفح الأمريكية.

- `03/04/2031` تعني **٣ أبريل**، ولا تعني ٤ مارس.
- يقبل الإدخال أرقامًا عربية أو إنجليزية أو فارسية، ثم يعرضها بالعربية.
- يمكن على لوحة الهاتف كتابة `٢٢٠٩٢٠٢٦`؛ تتحول إلى `٢٢/٠٩/٢٠٢٦`.
- يقبل مسار الحفظ ISO القديم للتوافق، لكن الحقول والجداول تعرض يوم/شهر/سنة.
- حقل التاريخ الفارغ يظل فارغًا؛ داخل الجدول يظهر `—` بدل `None`.
- المستحيل مثل ٣١ فبراير، أو انتهاء الخدمة/الشهادة قبل بدايتها، يُرفض قبل حفظ السجل أو رفع مرفقاته.

## المكونات

| المسؤولية | الملف |
| --- | --- |
| تحليل التواريخ والتحقق والتنسيق | `core/dates.py` |
| التوقيت المصري وتحويل timestamp إلى القاهرة | `core/egtime.py` |
| مصدر تحويل الأرقام المستخدم أيضًا في المتصفح | `core/arabic_numbers.py` |
| التحقق من تواريخ المجند قبل أي كتابة | `services/recruit_dates.py` |
| `datefmt` / `dateinput` وبيانات التقويم للقوالب | `core/web.py` |
| حقل التاريخ وعزل اتجاهه في الجداول | `templates/partials/dates.html` |
| منطق اليوم/الشهر/السنة في المتصفح | `static/js/dates.js` |
| تقويم عربي محلي وقابل للتنقل بلوحة المفاتيح | `static/js/date-picker.js` |
| تنسيق التقويم بنفس الكحلي والذهبي | `static/css/dates.css` |

كل حقل تاريخ جديد يستخدم `date_field`، لا `input[type=date]` الأصلي الذي قد
يعرض `mm/dd/yyyy`. تتوفر أزرار اختيار اليوم والمسح وتغيير الشهر والسنة، مع
أسماء عربية من `core/config.py` ونفس القائمة المنسدلة المخصصة.

## النطاق المطبق

- التاريخ أعلى الواجهة واليوم الحقيقي بتوقيت القاهرة.
- دخول الخدمة وانتهاؤها، وإصدار الشهادة الصحية وانتهاؤها: إدخالًا وعرضًا وتعديلًا.
- الإحصائيات والإشعارات، والحضور والإجازات والغياب وكشوف الطباعة.
- تاريخ النسخ الاحتياطية في اللوحة الرئيسية وصفحة الأرشيف، مع وقت القاهرة.
- تواريخ الإجازات والتحرير في ملفات Word المستخرجة. تُحدَّث كشوف الشهر المولّدة
  القديمة عند تنزيلها؛ لا يُعاد تحرير تصريح أرشيفي قديم بصمت.

## حماية البيانات

التخزين الداخلي يظل **`YYYY-MM-DD`** كما كان، للحفاظ على الفرز والمقارنة وحساب
الصلاحية وانتهاء الخدمة. لا يُنفّذ أي تحويل جماعي أو تبديل تلقائي للقيم القديمة.
حفظ السجل هو الحد الذي تُحوَّل عنده قيمة الإدخال المتحقق منها إلى ISO.

أسماء ملفات النسخ الاحتياطية ومعرفات الروابط وخصائص ملفات Office الداخلية
تقنية، وتظل ثابتة حتى لا يتعطل الاسترجاع أو تتغير الأرشيفات. التاريخ **المعروض**
للمستخدم منفصل عنها. عناوين الشهر/السنة وأرقام أيام شبكة التقويم ليست تواريخ كاملة،
ولا يُختلق لها يوم افتراضي.

لم تتغير ملفات الخطوط أو ألوان الواجهة أو لوجو المستخدم بسبب توحيد التواريخ.

## اختبار القبول

```bash
.venv/bin/python -m pytest tests/test_dates.py tests/test_date_flows.py -q
.venv/bin/python tests/browser/serve.py
# في طرفية أخرى، بعد تجهيز أدوات المتصفح حسب docs/APPEARANCE.md:
node tests/browser/dates.cjs
```

الاختبار يستخدم بيانات مؤقتة فقط، ويغطي متصفحًا `en-US` بتوقيت لوس أنجلوس
ومتصفحًا `ar-EG` بتوقيت طوكيو، مع بقاء التاريخ بتوقيت القاهرة وبصيغة اليوم أولًا.
يشمل السنة الكبيسة، الحفظ وإعادة فتح التعديل، رفض المدخلات الخاطئة، إلغاء الشهادة،
لوحة المفاتيح، الهاتف، وملفات Word. لا يُعد بديلًا عن قبول الطباعة الفيزيائية في Office.
