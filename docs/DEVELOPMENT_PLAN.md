## ما نُفذ (بوابة التسليم: pytest 130/1 + BROWSER_TAMEEDAT/APPEARANCE/DATES OK + لقطات معاينة)
1. **جدول المومدة بلا أعمدة متوسطات** — التبويب كما هو باقيًا (قرار المستخدم المصحّح).
2. **جدول القاموس الجديد**: متوسط ضباط/أفراد/مجندين + عدد التأميدات + زر «افتح التواريخ» (نافذة مشتركة: كل تأميدة من – إلى وهل كانت ملحقة وعلى مَن) + عمود «ملحقة؟» بشارة ×عدد مراتها مع أسماء من لُحقت بهم. المبني: `_dict_stats` في routes يدمج صفي الإحصاء (رئيسي/ملحقة) بعد month_summary الكامل بلا فلتر — أي تعديل إحصائي قادم يحتاج تعديلها.
3. **قاعدة القوائم المنسدلة صارمة**: قائمة نوع الملحقة صارت كومبو متمثّمًا (data-combo + enhance للصفوف المضافة ديناميكيًا) + إصلاح شبكتها (minmax بلا فيض). مسجلة كقاعدة 10 المقوّاة وقاعدة 22 في AGENTS.md.
4. **الرسائل قابلة للإغلاق**: زر ✕ لكل .toast وكل .flash بالمنظومة + عدّادات تلقائية كما كانت.
5. **كل ملفات الواجهة المفتوحة Excel**: مرآة xlsx RTL تُكتب للتويبات الثلاثة بعد كل حفظ (سجلات التأميدات/ملخص المومدة بورقة تواريخ/قاموس الجهات بالمتوسطات)، JSON يبقى داخليًا، وWord يبقى للتقرير الرسمي فقط.
6. لا يوجد — الخطة التالية تعرض قبل التنفيذ.

- [x] **الهوية والتشغيل (أوامر المستخدم)**: ترويسة الجانب أصبحت «وزارة الداخلية / منطقة وسط وجنوب سيناء — قطاع الأمن المركزي / قسم التعيينات — قطاع وسط سيناء» بدل «مخازن التعيينات»، والشريط الجانبي دمج «سجلات الامداد + سجلات المتعهد» في بند واحد «ملف السجلات». بجوار السنة النشطة: زرّا **«إنشاء سنة جديدة»** و**«نقل إلى الأرشيف»** بالنص الصريح بدل الأيقونات (الأرشفة بعد انتهاء السنة فقط، وتنقل الفولدر كاملًا إلى `database/الأرشيف`)، وحذف حرف «م» (الأفاتار). ولكل تبويب من التويبات الأربعة: «📂 فتح مجلد 《اسم التبويب》» + «📗 فتح ملف 《اسم الملف》» (قاعدة 21 في AGENTS.md — مع قاعدة 20 «البرمجة المحلية الملزمة»).
- [x] الاختبارات: ١٢٩+ اختبار Python ناجحًا (٢٧ للتاميدات بعد إضافات: الازدواج، المدة، استقلال الملحقات، الحذف —+ إعادة كتابة اختبارات الهوية) وأرقام عربية بخط أوضح للجداول والإحصائيات.

التسليم الحالي هو المعاينة؛ بناء Windows لهذه الدفعة لم يُنفَّذ بعد.
