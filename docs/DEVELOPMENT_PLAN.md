# خطة تطوير الإصدار ٢ — بعد موافقة المستخدم

## المتطلبات المعتمدة
- أصل القوة والدباجة مستقلان لكل شهر، مع نسخ صريح لشهر/سنة أخرى.
- اللوجو والدباجة داخل ملفات Excel الحقيقية، وليس معاينة الصفحة فقط.
- تنظيم الملفات في مجلدات ثابتة؛ الحفاظ على حد ١٠٠٠ سطر.
- نافذة Windows مستقلة وواجهة عربية مميزة، مع مثبّت لا يمس بيانات المستخدم.

## ما نُفذ في الكود
- [x] إصلاح مشغّل المصدر: بيئة معزولة، تحقق مكتبات، سجل أخطاء، لا نجاح وهمي.
- [x] هيكلة core / data_access / services / documents / desktop / scripts / tests.
- [x] سجل مجندين شهري ومرفقات شهرية، وتوابع الدباجة الشهرية.
- [x] معاينة النسخ، منع التكرار، تأكيد استبدال الدباجة، وعدم نسخ اليومية.
- [x] استيراد صريح من المصادر القديمة، مع نسخة احتياطية وحفظ أرقام ربط اليومية.
- [x] دباجة حقيقية ولوجو مضمن في كل شيت، مع التوقيعات وإعدادات A4.
- [x] تحديث الملفات القديمة عند تنزيلها، دون تغيير دباجة شهور أخرى.
- [x] واجهة عمل جديدة وخطوط محلية، بدون CDN عند الاستخدام.
- [x] نافذة pywebview وشريطها الخاص، خادم محلي خاص، حفظ وتنزيل داخل التطبيق.
- [x] إعداد PyInstaller وInno Setup، وتجميع WebView2 كامل للعمل دون إنترنت.
- [x] اختبارات بيانات معزولة، ملفات Office، ومسارات HTTP فعلية.

## بوابة التسليم
- [x] بناء المثبّت وتشغيل اختبارات Windows بنجاح على GitHub Actions.
- [x] اختبار نافذة WebView2 حقيقية: الدخول، وجود الجسر وأزرار النافذة، التكبير والاستعادة والإغلاق.
- [ ] اختبار النافذة يدويًا على Windows: التحريك، التكبير، التنزيل، طباعة A4، الإغلاق.
- [ ] اعتماد المستخدم لشكل مستند Excel على نسخة Office الخاصة به.

نجاح اختبارات Flask على Linux لا يعني اكتمال اختبار واجهة Windows.
ملف EXE غير موقّع بشهادة ناشر حاليًا؛ التوقيع الرقمي خطوة نشر لاحقة، ولا نعطّل برامج الحماية.

## تحقق الإصدار — ٢١ سبتمبر ٢٠٢٦

- اختبارات Python: **٣٩ ناجحًا**؛ جميعها في مجلدات مؤقتة معزولة.
- اختبار متصفح فعلي: الدخول، إظهار/إخفاء الشهادة، نسخ أصل القوة، عزل التعديل، رفع اللوجو، تنزيل Excel، التبويبات السبعة، وقائمة الهاتف.
- ملف Excel الذي نُزّل من المتصفح: أسطر الدباجة وصورة مضمنة داخل كل شيت.
- لا طلبات إلى خطوط/مكتبات خارجية أثناء اختبار الواجهة.
- Windows: بناء EXE والمثبّت، تشغيل EXE بعد التثبيت، نافذة أصلية، تحديث وإلغاء تثبيت مع بقاء بيانات المستخدم.
- البناء المعتمد: `dd693eb`؛ [النتيجة الناجحة](https://github.com/laaastfaucet2-hue/Logistics/actions/runs/35618779013).
- بيانات المستخدم الحقيقية لم يُضف إليها أي سجل تجريبي؛ تم التحقق من ذلك.
- المتبقي قبول يدوي لطباعة Office وشكل الملف على جهاز المستخدم، لا إعادة بناء البرنامج.
