# 📋 خطة تطوير قسم الراغبين الكاملة — (توجيه المستخدم ٣٠/٠٩/٢٠٢٦)

> ✅ **القرارات المؤكدة من المستخدم (٣٠/٠٩/٢٠٢٦):**
> 1. **عدد الوجبات = وجبة واحدة لليوم** — أي اسم راغب في اليوم = وجبة واحدة في كشف الشهر.
> 2. **كشف التجميع الشهري بالإجمالي فقط** (زي الصورة): م | الرتبة والاسم الكامل | عدد الوجبات.
> 3. **ملف اليوم = القوة كلها** بالعلامات (راغب ✓ / لا ✗ / مستثنى بعلامة مميزة).
> 4. **البذر التجريبي**: جهة «قطاع الشهيد اشرف جاد» بضباط الصور (محمد محمود / مصطفى عبدالحميد / ابراهيم ناجى — المستثنى) وتسجيل يوم ٢٢.

## ٢) الفهم النهائي للمطلوب (زي ما شرحت بالصور)

1. **الجهات والكوادر المعتمدة**: أسجل كل قوة الجهة الشرطية بالأسماء والرتب (ضباط + أفراد) مرتبين، وأقدر أعلامة أي اسم «غير راغب» (مستثنى) بسبب — وأي محاولة تسجيله راغب تتحذر. وأقدر أنسخ قوة الجهة لشهور أو سنة كاملة.
2. **الراغبين اليومي**: مربعات يوم ١..٣١ — أفتح اليوم والجهة وأشيل علامة راغب/لا على كل ضابط وفرد. وأي تعديل من **زرار التأميدة** أو من **تاب الراغبين** بيروح لنفس الداتا (ربط ١٠٠٪ بالاتجاهين).
3. **عدم الراغبين**: قائمة المستثنين (ضباط/أفراد) لكل جهة بالسبب.
4. **تجميع الكشف الشهري**: قائمة منسدلة بأسماء القطاعات/الجهات + زرارين (ضباط / أفراد) — أشوف كل ضابط/فرد خد كام وجبة في الشهر مقسومة على الأيام ١..٣١.
5. **زرار التأميدة**: نفس الداتا بالظبط + فحص تطابق: عدد التأميدة (مثال: ١٠ ضباط / ١٠ أفراد) مقابل الراغبين المسجلين فعليًا بالأسماء → بنر تنبيهات بالفرق (زي الصورة) + شيك بوكس تفعيل الفحص.
6. **الملفات المحلية**: ٤ فولدرات جوه قسم الراغبين — **بناء لحظي أقل من ثانية** ولو الإكسل مفتوح يتحدث أول ما يتقفل (نظام اللحظية الموجود).
7. **كل ملفات الراغبين بالدباجة والتوقيعات الرسمية المعتمدة** (مش زي الصور القديمة).
8. **كود القسم كله في فولدر واحد منظم** — كل تاب ملف منفصل، وزرار التأميدة كمان — مفيش لخبطة.

## ٤) قاعدة البيانات (month.db — جدولان جديدان)

```sql
-- قوة الجهات: الضباط والأفراد بالأسماء والرتب
CREATE TABLE ragh_persons (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  entity_id INTEGER NOT NULL,     -- جهة قاموس التأميدات نفسها (مصدر واحد)
  category TEXT NOT NULL,         -- 'officers' ضباط / 'individuals' أفراد
  rank TEXT DEFAULT '',           -- الرتبة (رائد / عقيد / ... أو درجة الفرد)
  full_name TEXT NOT NULL,        -- الاسم الرتبعي الكامل
  excluded INTEGER DEFAULT 0,     -- ١ = غير راغب (مستثنى من الراغبين)
  exclude_note TEXT DEFAULT '',   -- سبب الاستثناء (هلاكات/مأمورية/...)
  serial INTEGER DEFAULT 0,       -- الترتيب داخل الفئة
  created_at TEXT
);

-- تسجيل الراغبين يوم بيوم
CREATE TABLE ragh_daily (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  person_id INTEGER NOT NULL,
  day INTEGER NOT NULL,           -- ١..٣١
  willing INTEGER DEFAULT 1,      -- ١ راغب / ٠ لا
  source TEXT DEFAULT 'manual',   -- manual من التاب / tamida من زرار التأميدة
  UNIQUE(person_id, day)
);
```

- **الجهات = قاموس التأميدات نفسه** (مصدر واحد للربط ١٠٠٪ بين الزرار والتاب — والجهة الجديدة في التأميدة تنزل في القاموس زي ما هو شغال وتظهر في الراغبين).
- حقلا «راغبين ضباط/أفراد (أرقام)» في القاموس يفضلوا موجودين للتوافق، لكن الفحص الجديد بيقارن **بالأسماء الفعلية**.

## ٥) التابات الأربعة — تفاصيل كل تاب

### أ) تاب «الجهات والكوادر المعتمدة»
- قائمة الجهات (بنفس شكل قائمة السنين الزرقاء + بحث ذكي — قاعدة معتمدة).
- لكل جهة: تبويبان داخليان **الضباط / الأفراد والصف** — القوة بالترتيب: الرتبة + الاسم الرتبعي الكامل.
- علامة صغيرة لكل اسم: **«غير راغب»** (توجل) + خانة سبب — والاسم المستثنى يظهر مشطوبًا.
- إضافة عضو جديد سريع: فئة/الرتبة + الاسم + سبب (اختياري) — زي الصورة.
- بحث ذكي بالاسم أو الرتبة.
- **زر «نسخ القوة إلى شهر/سنة أخرى»** (جهة واحدة أو كل الجهات) — ينسخ الأسماء والرتب بلا تسجيلات يومية.
- منع تكرار نفس الاسم في نفس الجهة/الفئة + تحذير لو الاسم موجود مستثنى.

### ب) تاب «الراغبين (يومي)»
- مربعات أيام ١..٣١ (زي التأميدات) + اختيار الجهة.
- قائمة قوة الجهة (ضباط فوق — أفراد تحت) بالترتيب مع علامة راغب/لا لليوم المختار.
- **تحذيرات فورية** (بنر أصفر/أحمر):
  - اسم معلّم «غير راغب» اتحاول تعليمته راغب.
  - اسم في تسجيل اليوم مش موجود في قوة الجهة (اسم غريب).
  - عدم تطابق: عدد الراغبين فعليًا ≠ عدد التأميدة المسجل لليوم ده.
- عداد لحظي: «الضباط: ٢ من أصل ٣ — الأفراد: ٠ من أصل ١٠».

### ج) تاب «عدم الراغبين»
- لكل جهة: قائمة المستثنين ضباط/أفراد + السبب + تاريخ الاستثناء.
- زرار إرجاع الاسم للقوة (إلغاء الاستثناء) + بحث.

### د) تاب «تجميع الكشف العام»
- **قائمة منسدلة بأسماء القطاعات/الجهات + زرارين: ضباط / أفراد** (+ عرض).
- كشف الشهر: كل ضابط/فرد × عدد الوجبات في الشهر (التفصيل اليومي حسب إجابتك تحت).

---

## ٦) زرار التأميدة (الربط ١٠٠٪ بالاتجاهين)

- الزرار في صفحة اليوم بيفتح **نفس الديالوج اللي في الصور**: تبويب الضباط المسجلين + الأفراد والصف، بحث، تعليمات سريعة بالاسم (باكومبلِت من قوة الجهة)، إضافة اسم مباشر «وتحقق فوري»، عدادات، حفظ واعتماد.
- **نفس جداول الراغبين بالظبط** — أي تعديل من الزرار يظهر في التاب فورًا والعكس.
- شيك بوكس التأميدة: **«إضافة كشف الراغبين للتحقق من عدم تطابق أسماء الضباط والأفراد وتحذير النقص»** — لما يتفعّل: عند حفظ التأميدة يتقارن (عدد الضباط/الأفراد في التأميدة) × (الراغبين المسجلين فعليًا بالأسماء) → بنر تنبيهات بالفرق زي الصورة (تنبيه لا يمنع الحفظ).
- تحذير فوري لو الاسم المضاف: مستثنى «غير راغب» / مش في قوة الجهة.

## ٧) الملفات المحلية — «03-قسم الراغبين/»

```
03-قسم الراغبين/
├── 1. (يومي) الراغبين/
│   ├── يوم 1/ … يوم 31/            ← الفولدرات تتولد من أول الشهر (زي التأميدات)
│   │   └── <اسم الجهة>.xlsx         ← ملف لكل جهة يتحدث لحظيًا مع كل علامة
├── 2. عدم الراغبين/
│   ├── <اسم الجهة> (ضباط غير راغبين).xlsx
│   └── <اسم الجهة> (أفراد غير راغبين).xlsx
├── 3. تجميع الكشف الشهري العام/
│   └── <اسم الجهة>.xlsx             ← شيت ضباط + شيت أفراد (الإجمالي + الأيام)
└── 4. الجهات والكوادر المعتمدة/
    ├── <اسم الجهة> (ضباط).xlsx      ← القوة الكاملة بالرتب
    └── <اسم الجهة> (أفراد).xlsx
```

**تصميم الملفات:**
- كل الملفات **بالدباجة الرسمية المعتمدة (الترويسة + اللوجو + التوقيعات)** زي ملفات التأميدات الرسمية — مش زي الصور القديمة.
- **ملف اليوم للجهة**: م | الرتبة | الاسم الرتبعي الكامل | الفئة | راغب اليوم (✓) | ملاحظات/حالة — القوة كلها بالترتيب والمستثنين بعلامة مميزة (حسب تأكيدك تحت).
- **عدم الراغبين**: م | الرتبة | الاسم الرتبعي الكامل | ملاحظات / حالة الغياب (زي الصورة).
- **الكوادر**: م | الرتبة | الاسم الرتبعي الكامل | ملاحظات.
- **التجميع الشهري**: م | الرتبة والاسم الكامل | عدد الوجبات (+ عمود لكل يوم حسب تأكيدك).

**اللحظية (<١ ثانية):**
- كل علامة/تعديل → بناء **مستهدف** للملف المتأثر فقط (يوم+جهة واحد أو كشف واحد) عبر `atomic_save` — زمن بناء الملف الواحد أجزاء من الثانية.
- الملف المفتوح في Excel: نظام live-sync الموجود يكتبه تلقائيًا أول ما يتقفل (~٢ ثانية من القفل).
