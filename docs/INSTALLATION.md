# تثبيت مخازن التعيينات — Windows 10/11، ‏64-bit

## نسخة المثبّت

عندما ينجح مسار **Windows desktop installer** في GitHub Actions، نزّل ملف
`Logistics-Setup-2.0.0.exe` من الأثر `Logistics-Windows-x64-2.0.0`.
ملف SHA256 معه للتحقق من اكتمال التنزيل. الأثر متاح لمدة ١٤ يومًا.

المثبّت يضم البرنامج وPython والمكتبات، ومثبّت Microsoft WebView2 الكامل؛
لا يحتاج تحميل مكتبات عند تشغيل النسخة المثبتة. بناء المثبّت نفسه يحتاج الإنترنت.
لا تدّعي ملفات إعداد البناء وحدها وجود EXE جاهز؛ تحقق من نجاح مسار البناء أولًا.

- التثبيت لحساب المستخدم دون صلاحيات مدير.
- أيقونة على سطح المكتب وقائمة Start.
- نافذة مستقلة، بدون فتح متصفح أو نافذة أوامر.
- ملفات البرنامج: `%LOCALAPPDATA%\Programs\Logistics`.
- بيانات المستخدم: `%LOCALAPPDATA%\Logistics\database`.
- سجل أخطاء التطبيق: `%LOCALAPPDATA%\Logistics\logs\desktop.log`.
- تحديث البرنامج أو إلغاء تثبيته لا يحذف مجلد البيانات.

## نقل النسخة القديمة

١. أغلق البرنامج القديم وملفات Office المفتوحة، واحتفظ بنسخة من `database` على وسيط آمن.
٢. في أول تشغيل اختر **استيراد بياناتي القديمة** وحدد مجلد `database` نفسه.
٣. ينسخ البرنامج البيانات إلى مكانها الجديد؛ لا ينقل ولا يحذف المصدر.
٤. داخل الشهر المقصود، استخدم تنبيه **استيراد لهذا الشهر** للمجندين والدباجة العامة القديمة.
   لا تُوزّع البيانات تلقائيًا على كل الشهور. أرقام المجندين الداخلية تبقى مرتبطة باليوميات القديمة.
٥. للشهور التالية استخدم **نسخ أصل القوة / نسخ الدباجة**. اليومية لا تُنسخ معها.

إذا بدأت نسخة جديدة وبها بيانات بالفعل، فلن يستبدلها استيراد النسخة القديمة.
لا تنسخ قواعد SQLite يدويًا بينما التطبيق يعمل؛ استخدم النسخ الاحتياطية.

## تشغيل نسخة المصدر مؤقتًا

انقر `START.bat`. أول تشغيل فقط يحتاج إنترنت لتجهيز Python والمكتبات.
الإصدارات المدعومة في المصدر: Python 3.11–3.13 على Windows ‏64-bit.
يستعمل المشغّل `.venv` ولا يثبّت المكتبات في Python العام.
عند الفشل تبقى النافذة برسالة واضحة، والسجل في `runtime\logs\startup.log`.
المصدر يحفظ البيانات في `database/` بجانب `app.py`؛ المثبّت يفصلها عن ملفات البرنامج.

## بناء المثبّت على جهاز Windows

- ثبّت Inno Setup 6 من موقعه الرسمي `https://jrsoftware.org/isinfo.php`.
- شغّل `scripts\BUILD-INSTALLER.bat`.
- ينزّل البناء WebView2 من Microsoft ويتحقق من توقيعه الرقمي.
- يشغّل اختبارات البيانات، ثم يجمع التطبيق ويختبر الـEXE، ثم يصنع ملف التثبيت داخل `dist/`.
- أي فشل يوقف البناء؛ لا يُعلن نجاح بدون ملف صالح واجتياز الاختبارات.

## اختبار القبول اليدوي

على جهاز Windows نظيف بلا Python:
- تثبيت وفصل الإنترنت ثم فتح البرنامج وتسجيل الدخول.
- تكبير وتصغير وتحريك وإغلاق النافذة، ثم فتحها مرة أخرى.
- حفظ لوجو و٤ أسطر دباجة ثم تنزيل Excel؛ فحصها في كل الشيتات والطباعة A4.
- تجربة التنزيل، فتح المجلد، وكشوف Word وتصاريح الإجازة دون فتح متصفح.
- تعديل مجند ودباجة في شهر دون تغيير الآخر، وتجربة النسخ إلى سنة أخرى.
- تثبيت تحديث فوق النسخة ثم التحقق من بقاء البيانات والمرفقات.

المثبّت غير موقّع حاليًا بشهادة ناشر خاصة؛ قد يظهر تنبيه Windows SmartScreen.
تحقق من مصدر الملف وبصمته؛ لا تعطّل مضاد الفيروسات. النسخة النهائية للنشر الواسع يُنصح بتوقيعها.
