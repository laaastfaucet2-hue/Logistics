# مخازن التعيينات — Logistics Workspace

منظومة عربية RTL للمقررات وأصل القوة والمستندات الرسمية، بواجهة عمل داكنة بألوان slate/amber وخط Tajawal
ونسخة سطح مكتب Windows. كل شهر مستقل، والبيانات محلية ولا تُرفع إلى GitHub.

## تشغيل المصدر على Windows

انقر **START.bat**. يجهّز Python والمكتبات في بيئة معزولة ثم يفتح نافذة البرنامج، وليس متصفحًا.
أول تشغيل للمصدر يحتاج اتصالًا بالإنترنت. عند الفشل راجع `runtime/logs/startup.log`.

## نسخة التثبيت

تحديث الواجهة **٢٫١٫٠** يعتمد لوحة الألوان الداكنة slate/amber وخط Tajawal المحلي، مع قسم «التاميدات» كاملًا.
[تفاصيل الهوية واختبارها](docs/APPEARANCE.md). يُنشر رابط المثبّت الجديد بعد نجاح بناء Windows.
الرابط أدناه للإصدار السابق ٢٫٠٫٠.

**[تحميل مثبّت Windows ٢٫٠٫٠](https://github.com/laaastfaucet2-hue/Logistics/actions/runs/35618779013/artifacts/10647078612)** — بناء Windows ناجح، بتاريخ ٢١ سبتمبر ٢٠٢٦.
فك ZIP ثم شغّل `Logistics-Setup-2.0.0.exe`. الرابط متاح حتى ٥ أكتوبر ٢٠٢٦.

مسار **Windows desktop installer** على فرع `arena/01a0c425-logistics` يبني
`Logistics-Setup-2.0.0.exe` ويختبر النسخة المجمّعة والتثبيت والتحديث وإلغاء التثبيت.
بعد نجاحه تُتاح حزمة Windows في Artifacts لمدة ١٤ يومًا.
**ملفات إعداد البناء ليست بديلًا عن نجاح بناء Windows الفعلي.**

يشمل المثبّت Python والمكتبات ومتطلب WebView2 للعمل دون تحميل أثناء الاستخدام.
البيانات في `%LOCALAPPDATA%\Logistics\database`، منفصلة عن البرنامج ولا يحذفها التحديث.
في أول تشغيل يمكن استيراد مجلد `database` من النسخة القديمة دون المساس بالمصدر.

**[دليل التثبيت والنقل والبناء](docs/INSTALLATION.md)** · **[خطة التطوير وحالة الاختبار](docs/DEVELOPMENT_PLAN.md)**

## تشغيل معاينة الويب / التطوير

```bash
python -m venv .venv
# Windows: .venv\Scripts\python.exe
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

الخادم على المنفذ `5000`، مربوط بـ `0.0.0.0` للمعاينة.
للمعاينة خلف HTTPS استخدم `LOGISTICS_PREVIEW=1`.
واجهة المستخدم تستخدم روابط نسبية، بينما نسخة سطح المكتب تشغّل خادمًا خاصًا على loopback فقط.

حساب البداية المحلي: `mostafa` / `779`. لا تنشر النسخة بإعدادات الدخول الافتراضية على الإنترنت.

## بنية المشروع والبيانات

الكود مقسم إلى `core`, `data_access`, `services`, `documents`, `routes`, `desktop`.
القوالب والملفات الثابتة مستقلة. **[خريطة الملفات والقواعد الملزمة](CONTRIBUTING.md)**.

```
database/
├── system.db                 الحسابات والجلسات
├── backups/                  نسخ محلية (آخر ٤٠)
└── <السنة>/<رقم-الشهر>/
    ├── month.db              المقررات + الجهات + أصل القوة + اليومية + الدباجة
    ├── الدباجة/              اللوجو وWord لهذا الشهر
    ├── 08-المجندين/          المرفقات والكشوف
    └── <بقية الأقسام>/       ملفات Excel الرسمية
```

- الدباجة واللوجو مضمّنان في كل شيت Excel، والتوقيعات أسفل الجدول — على مستوى المنظومة كلها وقابلة للتعديل من صفحة الدباجة: يمينًا «رائد / مصطفى نصرالله» وشمالًا «مقدم / اسامة العجرودى» افتراضيًا (`db_letterhead.DEFAULT_SIGNATURES`).
- اختيار الشهر يغيّر أصل القوة والدباجة، ولا يؤثر تعديل أحدهما في شهر آخر.
- النسخ بين الشهور/السنوات بمعاينة وتأكيد؛ الأرقام العسكرية المكررة لا تُستبدل.
- الاستيراد من السجل العام القديم للشهر المختار فقط ويحافظ على ارتباط اليومية.
- التواريخ الظاهرة والمدخلة يوم/شهر/سنة **٢٢/٠٩/٢٠٢٦**، بتقويم عربي ثابت لا يتبع التنسيق الأمريكي للجهاز. التخزين الداخلي يظل ISO دون ترحيل القيم القديمة.
- الأرقام العربية والكميات بثلاث خانات عشرية عبر `core/arabic_numbers.py`.
- كل كتابة مستند ذرية، وSQLite محمي بـWAL؛ الاختبارات لا تمس بيانات المستخدم.

> معاينة Arena مؤقتة: إعادة بناء البيئة قد تمسح `database/` المُهمَل من Git.
> نزّل نسخة احتياطية للاحتفاظ ببيانات المعاينة؛ البيانات المحلية على جهازك منفصلة عنها.

## الاختبارات

آخر قبول: **٣٣٠ اختبار Python ناجحًا** (+ ١ متخطّى) بعد حذف قسم «التفاريد الحرة وتفاريد الدول» وزرّي المجلد والملف اليوميين في التاميدات وتطوير المساعد المحلي — منها ٣٢ للمساعد المحلي (فهم عربي وأرقام حقيقية وملفات الجهاز والمقارنة والنموذج المحلي الاختياري وشعار الضابط) و١٩ لمراجعة الأيام والتواريخ والحسابات و١٥ لحصر الملفات المحلية والتحديث اللحظي — واختبار متصفح فعلي للخط والألوان والتواريخ والتقويم العربي والهاتف.

### المساعد المحلي (أوفلاين)

مساعد عربي داخل البرنامج **بلا إنترنت وبلا أي خدمة خارجية**: يفتح أي تاب بالكلام،
ويجيب من بيانات الشهر النشط نفسها (ملخص · تأميدات يوم · جهة محددة · راغبون · مقررات ·
مخازن · أذون · مجندين · صحة · نسخ · مناسبات)، ويشرح المصطلحات وأدلة العمل، وشعاره
**ضابط** بدل أيقونة الروبوت. قراءة فقط ولا يعدّل أي بيانات.
تحت مربع السؤال **أسئلة سريعة بضغطة** (١٣ سؤالًا جاهزًا)، ونموذج لغوي صغير (**GGUF**)
اختياري تمامًا **بلا أي إعدادات داخل البرنامج**: تنزّل الملف من اللينك بنفسك وتحطه في
`database/assistant/models/` (ملف «اقرأني» داخل الفولدر فيه الخطوات بالتفصيل)، وقائمة
**«تبديل الموديل»** المنسدلة أعلى لوحة المساعد تختار «المكتبة الذكية» (محرك البرنامج
بلا موديل) أو أي موديل بالاسم من الموجود. التفاصيل في **[دليل المساعد المحلي](docs/ASSISTANT.md)**.

يسأل كذلك عن **ملفات جهازك**: «عدد الملفات» (حصر حقيقي من القرص) و«ملف تأميدات يوم ٧»
(رابط تنزيل فعلي)، وعن **المقارنة**: «مين أكبر جهة» و«أقل الجهات قوة»، وعن **مراجعة التسجيل**:
«أيام بدون تسجيل» (الأيام اللي فيها تأميدات ومفيش فيها راغب مسجّل).
[قاعدة التواريخ وطريقة الإدخال](docs/DATES.md).

```bash
.venv/bin/python -m pip install pytest==9.0.2
.venv/bin/python -m pytest tests -q
```

تشمل عزل الشهور، النسخ والترحيل، الدباجة والصور في Excel/Word، التنزيلات، وطلبات HTTP فعلية.
نافذة Windows والتنزيل والطباعة الأصلية تحتاج أيضًا اختبار القبول اليدوي الموضح في دليل التثبيت.

### دفعة ٠٦/١٠/٢٠٢٦ (ب)

- **📁 الملفات المحلية على جهازك**: لوحة شجرة في صفحتي «التاميدات» و«الراغبين» تعرض كل ملف
  على القرص باسمه وحجمه ووقت آخر تحديث، تتحدث تلقائيًا كل ٥ ثوانٍ، وتوسم الملفات التي
  اتحدثت للتو «⚡ اتحدث الآن».
- **التحديث اللحظي مضمون**: أي حفظ (تأميدة، راغب، قوة جهة) يُعيد كتابة ملفاته المتأثرة في
  نفس اللحظة، **ولو كان الملف مفتوحًا في Excel ولم يُقفل**: البرنامج يحتفظ بالتحديث ويكتبه
  فور إغلاق الملف (live-sync).
- **الواجهة**: كارت الدخول على اليمين بكل النص عربي يمين، ومفتاح الألوان في الفوتر بين
  جملتي الحقوق، والمكتوب في الشريط العلوي: «تصميم وتنفيذ رائد/ مصطفى نصرالله».

## دفعة ٠٦/١٠/٢٠٢٦

- **تنبيهات التاميدات ↔ الراغبين لكل أيام الشهر**: جدول واحد يُفتح ويُغلق في صفحتي
  «التاميدات» و«الراغبين»، يذكر أرقام الراغبين المسجلين فعلًا مقابل أعداد التأميدة،
  وينبّه أن الجهة غير مسجلة في «الجهات والكوادر المعتمدة» — والتنبيه لا يمنع الحفظ.
- **ملفات الراغبين اليومية**: «📂 فتح مجلد الراغبين» يفتح فولدر اليوم المفتوح نفسه،
  وبجوار كل جهة مسجلة زر «📗 فتح إكسل راغبين» لملف يومها.
- **تأميدات كل يوم يتب بيومه** (دفعة ٠٧/١٠/٢٠٢٦): في تبويب «تأميدات اليوم المحدد»
  **زر المجلد وزر الملف يتبعان اليوم المفتوح** — «📂 فتح مجلد «تأميدات يوم ٧»» و
  «📗 فتح ملف «تاميدات اليوم ٧.xlsx»» — وملف الشهر الكامل «إجمالي الشهر.xlsx» بجوارهما.
  وفي معاينة الويب: رسالة صادقة + تنزيل ملف اليوم فورًا بدل الفشل الصامت.
- **أوضاع ألوان البرنامج** أسفل الشريط الجانبي: كحلي (الافتراضي) · أبيض · أزرق —
  والاختيار يُحفظ على الجهاز ولا يمسّ ألوان المستندات الرسمية المطبوعة.
- **المساعد المحلي** (شارة جانبية بشعار ضابط تُفتح وتُغلق مثل الإشعارات، ومخفية في الطباعة):
  يسلم عليك، ويفتح أي تاب بالأمر، ويجيب أرقام الشهر الحقيقي ويشرح المصطلحات والأدلة —
  بلا إنترنت وبلا أي مكتبة خارجية. ونموذج لغوي صغير GGUF اختياري تمامًا للأوفلاين.
  وتحت اللوحة **أسئلة سريعة بضغطة** (أوصلتك بكل قسم عبر سؤال جاهز)، وأعلى اللوحة
  قائمة **«تبديل الموديل»** المنسدلة: «المكتبة الذكية» أو أي موديل GGUF بالاسم.
  ولتشغيل نموذج لغوي حقيقي أوفلاين: نزّل ملف GGUF من اللينك، حطه في
  `database/assistant/models/` (الخطوات بالتفصيل في ملف «اقرأني» جواه)، وثبّت
  المحرّك مرة واحدة بـ `pip install -r requirements-ai.txt`.
  التفاصيل: [docs/ASSISTANT.md](docs/ASSISTANT.md).
- **قيادات القسم** أسفل الشريط: رئيس قسم التعيينات مقدم/ اسامة العجرودى،
  وضابط بقسم التعيينات رائد/ مصطفى نصرالله.
- **بيانات معاينة جاهزة للعرض**: `LOGISTICS_SEED_DEMO=1 .venv/bin/python scripts/seed_preview_demo.py --reset`
  (جهات مومدة + كوادر وراغبين + مقررات، في الشهر النشط فقط — والسكربت يرفض العمل بلا المتغير الصريح).
