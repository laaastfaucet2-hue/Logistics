# 📦 منظومة مخازن التعيينات

نظام إدارة مخازن التعيينات — كل سنة وشهر منعزلان تمامًا عن غيرهما، وكل قسم له مجلد ملفات خاص به.

- **اللغة:** Python (Flask) — واجهة عربية كاملة RTL بثيم غامق فخم 🌙✨
- **الأرقام:** الإدخال والعرض بالأرقام العربية المشرقية (٠١٢٣...) مع قبول الأرقام الإنجليزية
- **البيانات:** مجلد `database/` كاملًا يبقى محليًا على الجهاز ولا يُرفع على GitHub

## ⚠️ قواعد الكود — إجباري قبل أي تعديل

> **١) لا يزيد أي ملف عن ١٠٠ سطر — بدون استثناء.**
> **٢) الكود في مكانه الثابت فقط طبقًا للترتيب المعماري — ممنوع ملفات عشوائية.**

القواعد الكاملة + خريطة المشروع: **[CONTRIBUTING.md](CONTRIBUTING.md)**

## التشغيل

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح المتصفح على: http://localhost:5000

## هيكل البيانات

```
database/
├── system.db            ← المستخدمون والجلسات وسياق السنة/الشهر
└── 2026/                ← سنة كاملة (إنشاء/حذف السنوات من شريط الأدوات العلوي)
    └── 01-يناير/        ← 12 شهرًا معزولًا (01-يناير ... 12-ديسمبر)
        └── 01-سجلات الامداد/  ← 12 مجلد قسم لكل ملفاته ... حتى 12-فواتير المتعهد
```

## الأقسام (القائمة الجانبية = أسماء الفولدرات)

سجلات الامداد — سجلات المتعهد — قسم الراغبين — المقررات التمونيية — مقررات المتعهد — مستودعات وسجلات — التاميدات — المجندين — الاحصائيات — المخازن والثلاجات — الترفية — فواتير المتعهد
