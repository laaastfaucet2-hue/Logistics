# 📦 منظومة مخازن التعيينات

نظام إدارة مخازن تعيينات التموين (أكل وشرب) — توريد، صرف للجهات والوحدات، أرصدة لحظية، تنبيهات نواقص، وتقارير.

- **اللغة:** Python (Flask)
- **قاعدة البيانات:** SQLite
- **الواجهة:** عربية كاملة (RTL) — ثيم غامق فخم 🌙✨

## التشغيل

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح المتصفح على: http://localhost:5000
